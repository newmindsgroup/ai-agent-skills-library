# Evidence-based personalization

Use only recipient details supplied by the user or verified through authorized research. A role or company category can guide language; it does not establish a specific problem, budget, hiring plan, or purchase intent.

Record the source and date of any observation used. Connect it to the offer with a question or explicitly tentative inference. Avoid pretending to have read an article, attended a talk, used a product, or spoken with someone when that did not occur.

When no individual evidence is available, write a neutral, relevant message about the actual offer. Do not block a draft-only request on optional research. Explain missing proof briefly only when it affects the user's choice.

Use the minimum personal information necessary. Keep client-specific evidence within its authorized client scope. Public visibility does not establish permission to reuse confidential context or to contact a person.

Review the result: does each personalized statement have a source; is an inference presented as fact; does the wording imply a relationship that does not exist; is the ask appropriate to the actual context?
