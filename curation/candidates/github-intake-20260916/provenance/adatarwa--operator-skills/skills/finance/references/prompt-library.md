# Finance Prompt Library — Reference

## Board pack financial narrative

```
Period: [Q/month]
Revenue: [actual vs budget vs prior]
Gross margin: [%]
OpEx: [actual vs budget]
Cash: [balance and runway]
Key variances: [what differed and why]
Outlook: [view on next quarter]

Write financial narrative under 500 words. Lead with most important
headline. Don't bury bad news — surface with plan to address.
Plain English. End with what board needs to decide.
```

## Investor update

```
Metrics this month: [paste]
Highlights: [what went well]
Lowlights: [what didn't]
Asks: [what you need from investors]

Under 400 words. Honest — investors detect spin.
Specific, not vague. 1-2 concrete things they can help with.
```

## Scenario analysis

```
Base case assumes:
- Revenue growth: [X]%
- Gross margin: [X]%
- Key cost assumptions: [list]

Help build bear/bull cases:
1. Which assumptions are most sensitive to change
2. Realistic ranges for each
3. One-paragraph narrative per scenario
Bear trigger: [cause] | Bull trigger: [cause]
```

## Budget variance explanation

```
Variances vs budget: [paste table or describe]

For each significant variance (>5%):
- One-sentence cause explanation
- One-time vs recurring distinction
- Recoverable this quarter? Y/N

Then summarize overall picture in 3 sentences for the CEO.
```

## Expense policy

```
Company: [size, industry]
Context: [remote/office, travel-heavy, etc.]
Goals: [clear rules, fast reimbursement, etc.]
Categories to address: [meals, travel, software, etc.]

Format: purpose, who it applies to, approval requirements by amount,
what's reimbursable with limits, what's not, submission process, timeline.
```

## Explain financial concept to non-finance audience

```
Concept: [e.g. gross margin, burn rate, unit economics]
Audience: [e.g. sales team, board, new hire]

Explain:
1. One-sentence simplest definition
2. A paragraph of context for why it matters
3. A concrete example with round numbers
4. What good vs bad looks like for a company like ours
```

## Contract financial review (first pass)

```
Review this vendor contract for financial/commercial risks.
[paste contract or key sections]

Identify:
1. Payment terms and cash flow implications
2. Price escalation clauses
3. Auto-renewal provisions and notice periods
4. Termination clauses and penalties
5. Unusual financial commitments
6. Top 3 things to negotiate before signing

Note: first-pass only — verify with legal before signing.
```
