# Procurement Prompt Library — Reference

## Full RFQ

```
Item/service: [what we need]
Company: [industry, size, context]
Quantity/volume: [amounts]
Required delivery: [timeline, location]
Technical specs: [paste or describe]
Evaluation criteria: [price/quality/lead time/other]
Submission deadline: [date]

Format: intro + background (2 sentences), scope of supply,
technical requirements, commercial terms required, evaluation
criteria with weighting, submission instructions and deadline.
```

## RFQ follow-up (non-responsive supplier)

```
Sent RFQ on [date], deadline [date], no response.
RFQ was for: [brief description]
Relationship: [new/existing, importance]

Under 100 words. Not desperate. Ask for response or reason
for non-response within 48 hours. Leave door open if needed.
```

## Supplier evaluation scorecard

```
Category: [what we're sourcing]
Priorities ranked: [list]
Suppliers being evaluated: [list]

Build: 10-12 weighted criteria (sum to 100%), 1-5 scoring guide,
total score calculation, recommendation framework.
Also: 5 questions that reveal real supplier performance.
```

## Compare received quotes

```
Supplier A: [paste quote details]
Supplier B: [paste quote details]
Supplier C: [paste quote details]
Our requirements: [what matters most]

Give: side-by-side comparison table, total cost of ownership
for each (not just unit price), non-price factors to consider,
recommendation with reasoning, what to negotiate with the winner.
```

## Contract first-pass review

```
[paste contract]

Look for: payment terms vs industry standard, price escalation
clauses, minimum purchase commitments, termination rights (ours
and theirs), liability limitations, IP ownership, auto-renewal traps,
top 5 clauses to negotiate.

NOTE: preliminary review only — legal team reviews before signing.
```

## Negotiation preparation

```
Negotiating: [contract/renewal] with [supplier]
Current terms: [key terms]
Our ideal outcome: [target]
Minimum acceptable: [floor]
Our leverage: [why they need us]

Prepare: opening position and presentation, likely counter-
arguments and responses, low-cost concessions to offer, walk-away
position stated professionally.
```

## Supplier performance review (quarterly)

```
Supplier: [name, what they supply]
This quarter: on-time delivery [%], quality [defect rate],
responsiveness [assessment], price competitiveness [vs market]
Issues: [describe] | What went well: [describe]

Write: pre-meeting agenda email, structured 60-min agenda,
performance summary to present, how to address issues without
damaging the relationship.
```

## Supplier improvement plan letter

```
Issue: [late deliveries/quality/etc.]
Duration: [how long]
Impact: [operational/financial]
Previous conversations: [what's been said]
Alternatives available: [yes/no]

Write: states issue with data, specific 30/60/90 day timeline,
clear definition of success, consequences stated without
unnecessary aggression. Relationship should survive a good response.
```

## Procurement savings report

```
Period: [quarter/year]
Savings achieved: [list initiatives and amounts]
Methodology: [how calculated]
Future pipeline: [what's coming]

Lead with total savings headline. Explain methodology credibly.
Show pipeline. Under 400 words. Never overstate beyond what shows in P&L.
```
