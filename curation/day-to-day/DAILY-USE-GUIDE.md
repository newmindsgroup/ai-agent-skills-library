## Project-only and future additions

Provider and framework specialisms belong with known owning projects. Preserve source and rollback until migration is explicit. Do not install a new skill because a daily task has a matching keyword. First check this guide, the full register and existing plugins. For a real gap, add a bounded candidate with provenance, dependency checks and representative tests.

The full register records latest-seen activation states; plugin entries absent from the latest refresh may retain older states. The current discovery summary reports the latest workspace snapshot. This guide narrows task selection while the broader cleanup continues; it does not silently disable every unlisted skill.
