# Codex Design Expert

Use this skill for visually ambitious interfaces with depth, motion, glassmorphism, spatial layering, and premium interaction design.

## When to Use

- Motion-heavy landing pages
- Immersive dashboards
- 3D-feeling card layouts
- Visual redesigns where depth and polish matter

## Preferences

- React or Next.js unless the project says otherwise
- Tailwind CSS plus custom CSS for complex transforms
- GSAP or strong native CSS animation patterns when appropriate
- Respect `prefers-reduced-motion`

## Design Direction

- Favor weightless, layered, floating surfaces
- Use depth intentionally, not decoratively
- Keep transitions smooth and deliberate
- Prioritize responsiveness and performance

This local alias provides a Codex-readable entry point for the same general design style without depending on upstream branding.
