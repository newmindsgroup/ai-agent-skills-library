# UX Strategy

Use this skill to design the experience before designing the screen.

For app-specific or multi-step product flows, route to `/Users/newmindsgroup/.codex/skills/app-flow-designer/SKILL.md` as the more concrete execution skill and use this skill as the higher-level strategy layer.

## Focus

- goals, user intent, and success criteria
- user journeys and task flows
- decision points, friction, and drop-off risk
- information architecture and navigation
- onboarding, forms, checkout, booking, signup, and lead flows
- prioritizing what the user needs to see, know, and do next

## Workflow

1. Define the user type, their job-to-be-done, and the business goal.
2. Map the flow from entry point to completion.
3. Identify:
   - moments of confusion
   - trust gaps
   - cognitive overload
   - missing proof or guidance
   - unnecessary steps
4. Propose a better sequence with clear states, content priorities, and actions.
5. If helpful, translate the strategy into:
   - flow outline
   - page/section hierarchy
   - wireframe-level recommendations
   - experiment ideas

## Default Deliverables

- UX strategy memo
- simplified user flow
- friction and opportunity list
- recommendations by priority

## Guardrails

- Strategy first, screens second
- Reduce complexity before adding UI
- Favor clarity, confidence, and momentum
- Explain tradeoffs when changing flow structure
