# Landing Page Critique

Use this skill to audit landing pages and high-conversion website pages.

## Review Scope

- hero clarity
- problem and promise
- proof and objections
- CTA hierarchy
- section flow
- visual hierarchy
- responsiveness basics
- accessibility basics
- overall conversion friction

## Workflow

1. Start with StoryBrand-first page logic unless the user asks for a different framework.
2. Audit the page using the rubric.
3. Prioritize findings by conversion risk and clarity risk.
4. Recommend concrete rewrites or restructuring.

## Outputs

- prioritized findings
- rewrite recommendations
- section-order recommendations

## Guardrails

- findings first, summary second
- do not separate copy, UX, and visual issues when they are one problem
