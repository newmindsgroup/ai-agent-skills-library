# Starter Packs

Starter packs are curated subsets for people who want a useful install without loading the entire library.

Install a pack with:

```bash
curl -fsSL https://raw.githubusercontent.com/newmindsgroup/ai-agent-skills-library/main/install.sh | bash -s -- --bundle codex-essentials
```
