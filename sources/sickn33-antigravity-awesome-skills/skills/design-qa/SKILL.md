Use this skill to standardize visual and UX quality checks after a design or implementation exists.

Use screenshots, browser captures, or Figma screenshots when available. Prefer screenshot-driven review over abstract judgment.

## Scope

- visual hierarchy
- CTA prominence
- spacing consistency
- mobile and desktop behavior
- state coverage
- accessibility basics
- overall polish

## Workflow

1. Identify the surface and artifact type.
2. Review the UI against the checklist and style defaults.
3. Prioritize launch blockers before polish notes.
4. Separate visual, UX, and responsive findings only when it improves clarity.

## Outputs

- prioritized QA findings
- launch blockers
- polish recommendations
